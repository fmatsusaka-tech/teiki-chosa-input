# teiki-chosa-output連携契約

正式な列定義は[Input正本データ辞書](input-data-dictionary.md)を参照してください。

## 境界

- Inputの`調査原票`が観測データの唯一の正本です。
- Outputは正本を読み取るだけで、予測値、AIコメント、集計値をInputへ書き戻しません。
- Outputは`登録ID`を主キーとして扱い、行番号や列番号には依存しません。
- 差分取込では`登録ID`と`改訂番号`を使用します。
- `編集キーハッシュ`はInput内部の秘密情報であり、Outputへ連携しません。

## 互換性

既存列の意味変更と削除は行いません。Inputが列を追加しても、Outputは未知の見出しを無視し、
既知の見出し名で値を解決します。欠測した数値は`0`ではなく`null`として扱います。

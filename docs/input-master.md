# 入力マスタと補正学習データ

## 入力マスタ

開発用データバンクの `入力マスタ` タブを、文章解析で使用する正式マスタとします。
アプリの再公開は不要で、次回の画面読み込みから編集内容が反映されます。

| 見出し | 内容 |
| --- | --- |
| 種別 | `園地`、`品種`、`処理区` のいずれか |
| 正式名称 | 確認画面と調査原票へ使用する名称 |
| 別名 | メモに現れる別表記。複数の場合は読点・カンマ・セミコロンで区切る |
| 既定品種 | 種別が園地の場合に自動設定する品種。分からない場合は空欄 |
| 有効 | チェック済みの行だけ解析に使用 |

### 早生品種の正式名称

次の入力名は、すべて正式品種名 `早生（宮川・興津 等、又は山下紅）` として扱います。

- 宮川
- 興津
- 山下紅
- 早生

`入力マスタ`では、正式名称を上記の正式品種名、別名を
`宮川、興津、山下紅、早生`として登録してください。園地の既定品種にも短縮名ではなく
正式品種名を使用します。

マスタを取得できない場合は、アプリ内の組み込みマスタへ自動的に切り替わります。
未登録の園地名でも、後ろに数値のまとまりがあれば警告付き候補として解析し、
利用者が園地名・品種などを補正できます。

確認・補正画面の品種欄には、有効な品種マスタを入力候補として表示します。
候補は入力を制限するものではなく、新品種やマスタ外の解析結果も自由入力できます。
マスタとの不一致を理由に解析や登録操作を停止しません。

## 解析補正ログ

文章入力を確認・補正して調査原票へ保存したとき、学習材料として
`解析補正ログ` タブへ次の組み合わせを記録します。

- 原文メモ
- 補正後の園地名・品種・処理区・備考
- 補正後の横径・糖度・酸度
- 入力方法

補正ログへの記録に失敗しても、正本である `調査原票` の保存は取り消しません。
将来の夜間学習処理はこのログを入力とし、正本を書き換えないものとします。
